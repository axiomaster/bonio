# Magic Cue（魔法胶囊）— 原始 PRD

日期：2026-09-05
状态：待 PM 澄清细化

## 背景

Magic Cue 是 Pixel 手机上的一项特色功能：当屏幕内出现相关信息时，Magic Cue 会自动提醒用户。
例如在聊天页面，朋友问你晚上约会的餐厅电话、地址、日程、航班等信息时，Magic Cue 识别到之后，
会自动弹出一个胶囊，里面显示对应的信息；点击胶囊就可以在聊天中直接发送给朋友。

## 需求（用户原始描述）

在 Bonio（HarmonyOS 版）上实现类似功能。当前 Bonio 的 avatar 在双击时会自动识别屏幕内容，
以此为基础：

1. **数据源调研**：bonio app 如何在 HarmonyOS 设备上访问获取联系人、短信、备忘录、日历信息。

2. **匹配识别**：当用户点击（双击 avatar）识别屏幕时，识别屏幕内容里是否有"询问联系人、
   短信、备忘录、日历相关信息"，并与本地数据匹配。

3. **胶囊 UI 与交互**：
   - avatar 当前在顶部会有提示文字；请在双击匹配到可推荐的内容时，从侧边弹出一个横条胶囊，
     里面显示相关信息；
   - 用户点击胶囊后，调用写入能力，把内容填入当前聊天应用的输入框并发送出去；
   - avatar 用户一般不会停留在屏幕正中央，都在底部偏左或偏右的位置：
     - avatar 位于屏幕**右边** → 提示胶囊从 avatar **左边**弹出；
     - avatar 位于屏幕**左边** → 提示胶囊从 avatar **右边**弹出。

## 待澄清问题（PM 整理）

- 触发方式：仅双击手动触发，还是后续要支持被动自动识别（Pixel 原版为被动触发）
- 备忘录来源：系统备忘录无公开 API，是否用 Bonio 自己的 memo 存储
- 点击胶囊后：直接发送 vs 仅填入输入框等待用户确认
- 隐私：屏幕内容送云端 LLM 处理是否可接受（当前双击识别即走此链路）
- 覆盖哪些聊天应用（微信为主？）
