# Raw PRD：Bonio 皮肤导入（Skin Import）

> 日期：2026-09-26
> 来源：用户口述需求（原始记录，未加工）
> 状态：已精化为 `docs/design/prd/skin-import-prd-20260926.md`

## 用户原话

请实现 bonio 皮肤导入功能：

1. 用户可以从本地选择皮肤 zip 包，导入后就支持切换皮肤；
2. 用户也支持指定链接，只要指定链接下载结果为支持的 zip 包格式即可。

完成这个功能，需要：

1. 定义皮肤 zip 包的打包方式，以及里面需要包含的所有素材、配置文件等，以及素材的要求；
2. 支持本地及在线链接导入方式。

## 边界备注

- 当前聚焦 **Android 移动版本**开发；本功能只做 Android 端，桌面/HarmonyOS 不在本次范围。
- 现有内置皮肤（cat/kun/mario/messi，sprite sheet 8×9 网格）保持可用，导入皮肤与内置皮肤并列展示、可切换。
