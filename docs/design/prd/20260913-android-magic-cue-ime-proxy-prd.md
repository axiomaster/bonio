# Android 平台 Magic Cue 交互与静默注入 PRD

- **日期**：2026-09-13
- **状态**：已确认
- **涉及平台**：Android
- **关联需求**：双击 Avatar 视觉防抖与解耦、微信聊天界面 Magic Cue 意图提取、免拉起软键盘静默注入并发送

---

## 1. 背景与核心痛点

Pixel Magic Cue（魔力锦囊）的核心价值在于跨应用上下文预判，当好友在聊天时询问某项信息（如手机号码、餐厅地址、航班号、日程等），能够即刻在输入场景旁提供直接答案，并一键完成发送。

在 Android 端落地 Magic Cue 的实际验证过程中，暴露了以下三个核心痛点：

1. **Avatar 交互闪烁与坐标偏移**：
   - 旧方案在双击截图时将悬浮窗设为 `INVISIBLE`，导致 Avatar 视觉上瞬间消失又出现（严重闪烁）。
   - 悬浮窗采用单窗口布局包裹头顶气泡、Avatar、侧边胶囊，文本变化或胶囊显隐导致浮窗宽度动态伸缩，并产生位移补偿死循环，导致 Avatar 左右晃动、难以点击。
2. **微信等主流聊天软件无障碍隔离与空建议问题**：
   - 微信聊天页面的无障碍节点树受到系统或客户端防护（`childCount=0`），无法直接提取结构化聊天文本。
   - 必须通过 Vision 截图降级并送入 LLM 模型分析；历史方案中本地服务未连通时直接报错并导致前端弹窗“当前页面没有什么可以帮你”，体验割裂。
   - 随着架构全面摒弃 hiclaw，需对齐统一使用端侧/局域网 DSH 模型通道。
3. **点击胶囊后的填入体验（键盘遮挡与复制降级）**：
   - 现有无障碍注入方案（`ACTION_SET_TEXT`）在微信未聚焦输入框时会被拦截。
   - 降级为模拟点击输入框呼出软键盘后注入，但软键盘弹起会遮挡一半屏幕、破坏聊天氛围。
   - 再次降级为“已复制到剪贴板，请长按粘贴”，操作断层，违背了 Magic Cue“一键直达发送”的产品初衷。

---

## 2. 产品方案与功能设计

### 2.1 交互与视觉规范：零闪烁、零位移双 Window 架构

- **常态稳定**：Avatar 悬浮窗物理尺寸固定为 `160dp x 140dp`，Avatar 实体居中固定在 `(30dp, 36dp)` 锚点位置，头顶状态文本气泡水平居中，气泡字数变化绝不引起 Avatar 本体 1 像素的位置移动。
- **双击零闪烁**：用户双击 Avatar 触发 Magic Cue 时，Avatar 保持常驻屏幕，无缝切换为 Thinking 动画和“正在分析屏幕…”头顶状态，后台并行执行截屏与上下文分析，绝不隐藏 View。
- **独立侧边胶囊**：
  - 胶囊使用独立的 `TYPE_APPLICATION_OVERLAY` 窗口；
  - 根据 Avatar 在屏幕所处左右半屏动态挂载：
    - Avatar 位于屏幕左半边：胶囊平滑从右侧滑出；
    - Avatar 位于屏幕右半边：胶囊平滑从左侧滑出；
  - 胶囊展示或隐藏完全不触碰 Avatar 主窗口，两者生命周期与布局彻底解耦。

### 2.2 文本识别与 Vision 降级策略

- **结构化文本优先**：尝试从 Accessibility 节点树读取；
- **视觉截图兜底**：若节点树受限（如微信 `childCount=0`），自动进入无感截图 Vision 模式，将图片送入 DSH 统一分析；
- **空结果与状态反馈优化**：
  - 若后台分析中出现网络或模型错误，给予明确的状态引导；
  - 若屏幕确无信息询问意图，静默完成记忆记录（“已记住 ✅”），不干扰用户。

### 2.3 免弹软键盘静默注入（IME Proxy 方案）

- **产品目标**：用户点击 Magic Cue 侧边胶囊上的“发送”按钮，**不弹起任何系统软键盘**，在 100ms 内直接将建议文本填入微信/当前应用的聊天输入框并触发发送。
- **实现手段**：提供轻量虚拟输入法代理（`BonioImeService`）。
  - 该输入法对外声明高度为 0、全透明无 UI（`onEvaluateInputViewShown() = false`）；
  - 点击“发送”时，由后台直接通过 `currentInputConnection.commitText(text, 1)` + `performEditorAction(EditorInfo.IME_ACTION_SEND)` 静默写入并发出；
  - 正常打字时无缝回切或代理系统输入法。

---

## 3. 验收标准

1. **手势与视觉稳定性**：双击 Avatar 时，Avatar 零闪烁、零晃动，头顶文字正常更新，双击后 100% 保持在原坐标。
2. **胶囊弹出规范**：分析完成后，胶囊在 Avatar 远离屏幕边缘的一侧平滑弹出，点击空白处或超时 15s 自动淡出收起。
3. **一键直发验证**：在微信聊天页面点击胶囊“发送”，建议内容直接填入微信输入框并完成发送，过程无需长按粘贴，无需拉起全屏软键盘。
