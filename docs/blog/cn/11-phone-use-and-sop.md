# 端侧原生 GUI Agent 与 SOP：让 AI 真正操作你的手机

> 当你对 AI 伴侣说：“帮我用剪映剪一个春节短片”，或者“再帮我点一杯上次喝过的冰美式”，它不再是只能给你列出几点文字建议，而是直接在手机上滑动、点击、选素材、下单。

---

## 场景：从“动嘴”到“动手”

传统的手机 AI 助手通常只能停留在“回答问题”或“打开某个 App”。当遇到跨步骤、多页面的复杂流程时（例如在相册选图、在剪映里套模板、在美团里核对生椰拿铁的冰度糖度并加购），往往就无能为力了。

而基于 PC 的端侧自动化（如 Open-AutoGLM）需要手机连接电脑并走 ADB/HDC 调试，延迟高且根本无法离开电脑桌。

Bonio 在 HarmonyOS 移动端上实现了 **端侧原生运行的 GUI Agent（`phone-use-harmonyos`）**，并结合 **SOP（标准操作规程）体系**，让 AI 搭子拥有了真正“在手机上帮你办事”的能力。

---

## 架构：本地闭环的端侧 GUI Agent

在 Bonio 的手机端体系中，端侧原生 GUI Agent 直接运行在设备本地（AArch64 musl C++ 原生程序），无需借助任何外部电脑：

```text
       ┌────────────────────────┐
       │   Bonio Avatar / Chat  │ (用户语音/打字发指令)
       └───────────┬────────────┘
                   │
                   ▼
       ┌────────────────────────┐
       │     端侧 DSH Agent     │ (调度与规划)
       └───────────┬────────────┘
                   │ 调用 on-device skill
                   ▼
       ┌────────────────────────┐
       │  phone-use-harmonyos   │ (本地原生 C++ CLI)
       │  /data/local/bin/      │
       └─────┬────────────┬─────┘
             │            │
             ▼            ▼
      /bin/snapshot   /bin/uitest
         (截屏)        (点击/滑动/输入)
```

1. **零电脑依赖**：随身携带，随时随地在真机上本地执行；
2. **极速闭环**：截图、Base64 转码、GLM 视觉模型请求、`uitest` 输入模拟全部在端侧完成；
3. **断点保护与可控性**：单任务设置安全步数上限（默认 20 步），随时支持用户物理中断。

## SOP：为什么必须有“标准操作规程”？

许多人在尝试手机 GUI Agent 时发现：如果完全让大模型在屏幕上“自由探索”，常常容易出现以下问题：
- **迷失在复杂页面**：大模型可能会被页面的广告弹窗、次要功能吸引，绕远路；
- **误解控件逻辑**：例如在系统相册 Picker 中，点击照片中间其实是“大图预览”，只有点击右上角或右下角的小圆点才是真正“选中”；
- **步数耗尽**：一个原本 3 步能搞定的操作，盲目尝试了 20 步还没完成。

为此，Bonio 引入了 **SOP（Standard Operating Procedure，标准操作规程）**。

SOP 就像给 AI 搭子的一份**精简高分通关秘籍**：

| 应用场景 | 自由探索的困境 | SOP 引导下的确定性操作 |
|---|---|---|
| **剪映视频制作** | 尝试在复杂的多轨道时间轴上拖拽音频与特效，极易错乱 | **“剪同款”模板优先**：直奔 Tab 2 搜索模板，批量填入素材，由模板自动完成特效与配乐 |
| **系统相册选图** | 频繁点击图片正中进入全屏预览，导致任务中断 | **必须点击宫格右下角小圆点**，精准勾选素材 |
| **外卖/饮品复购** | 盲目重选商品，经常挑错规格和温度 | **严格匹配记忆数据**（品名、冰量、糖度），加购完成后**停留在支付确认页**由用户最终把关 |

## 目录与配置规范

为了便于统一维护，手机端相关文件与 SOP 规范部署位置如下：

- **核心可执行文件**：
  `/data/local/bin/phone-use-harmonyos`
- **运行时配置文件**：
  `/data/local/.phone-use-harmonyos/phone-use-harmonyos.conf`
- **DSH 技能与 SOP 根目录**：
  `/data/local/home/.dsh/skills/`
  - `phone-use-harmonyos/SKILL.md`（宏观调度 SOP）
  - `cap-cut/SKILL.md`（剪映操作 SOP）
  - `ohos-cli-tool/SKILL.md`（设备命令 SOP 与 Schema 集合）
