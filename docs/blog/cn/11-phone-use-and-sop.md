# 端侧原生 GUI Agent 与 SOP：让 AI 真正操作你的手机

> 当你对 AI 伴侣说：“帮我再点一次上次喝过的咖啡”，或者“帮我用剪映做个生活短片”，它不再只是给你列出几点文字建议，而是直接在手机上滑动、点击、选规格、加购。

---

## 场景：从“动嘴”到“动手”

传统的手机 AI 助手通常只能停留在“回答问题”或“打开某个 App”。当遇到跨步骤、多页面的复杂流程时（例如在相册选图、在剪映里套模板、在微信小程序里核对瑞幸咖啡的规格并一键复购），往往无能为力。

而基于 PC 的端侧自动化（如 Open-AutoGLM）需要手机连接电脑并走 ADB/HDC 调试，延迟高且根本无法离开电脑桌。

Bonio 在 HarmonyOS 移动端上落地了 **端侧原生运行的 GUI Agent（`phone-use-harmonyos`）**，并深度集成了全新的 **`SopManager`（标准操作规程管理器）**，让 AI 搭子拥有了真正“在手机上帮你办事”的高确定性能力。

---

## 架构：本地闭环的端侧 GUI Agent

在 Bonio 的手机端体系中，端侧原生 GUI Agent 直接运行在设备本地（AArch64 musl C++ 原生程序），无需借助任何外部电脑：

```text
       ┌────────────────────────┐
       │   Bonio Avatar / Chat  │ (用户语音/打字发指令)
       └───────────┬────────────┘
                   │
                   ▼
       ┌────────────────────────┐
       │     端侧 DSH Agent     │ (调度与规划)
       └───────────┬────────────┘
                   │ 调用 on-device skill
                   ▼
       ┌────────────────────────┐
       │  phone-use-harmonyos   │ (本地原生 C++ CLI)
       │  /data/local/bin/      │
       └─────┬────────────┬─────┘
             │            │
             ▼            ▼
      /bin/snapshot   /bin/uitest
         (截屏)        (点击/滑动/输入)
```

1. **零电脑依赖**：随身携带，随时随地在真机上本地执行；
2. **底层平台抽象**：引入 `IPlatform` 抽象层，完美适配 HarmonyOS 的 `snapshot_display` 与 `uitest uiInput`；
3. **断点保护与可控性**：单任务设置安全步数上限（默认 20 步），随时支持用户物理中断（Ctrl+C）。

## SOP：为什么必须有“标准操作规程”？

许多人在尝试手机 GUI Agent 时发现：如果完全让大模型在屏幕上“自由探索”，极易在复杂 UI 中迷失：
- **迷失在广告弹窗**：被营销活动弹窗遮挡，死循环点击被遮蔽的按钮；
- **误解控件逻辑**：在系统相册 Picker 中，点击照片中间只是“全屏预览”，只有点击右下角的小圆点才是真正“选中”；
- **缺乏安全底线**：在支付、下单环节缺乏边界意识。

为此，Bonio 研发了 **SOP（Standard Operating Procedure，标准操作规程）管理体系**。

SOP 就像给 AI 搭子的一份**通关秘籍与避坑指南**：

| 应用场景 | 自由探索的困境 | SOP 引导下的确定性操作 |
|---|---|---|
| **瑞幸咖啡再来一单** | 迷失在首页领券弹窗，或盲目重选商品导致规格不一致 | **弹窗必关 -> 订单页 -> 历史订单 -> 再来一单 -> 核对自提门店**。到达待支付页即完成目标，**严禁自动点击“立即支付”**，留给用户手动确认。 |
| **剪映视频制作** | 尝试在复杂多轨道时间轴上编辑，极易错乱 | **“剪同款”模板优先**：直奔 Tab 2 搜索模板，批量填入素材，由模板自动完成特效与配乐。 |
| **系统相册选图** | 频繁点击图片正中进入全屏预览，导致任务中断 | **必须点击宫格右下角小圆点**，精准勾选素材。 |

## SOP 的使用与配置部署规范

全新的 `phone-use-harmonyos` 提供了高度灵活的 SOP 扩展机制：

1. **开箱即用的内置 SOP**：
   - 固化了 `luckin_coffee_reorder`、`capcut_template`、`wechat_send_message`。
2. **外部 JSON 动态扩展（无需重新编译）**：
   - **手机端标准配置文件部署目录**：
     ```bash
     /data/local/.phone-use-harmonyos/sops/
     ```
   - 只要在该目录下新增一个符合规范的 `<name>.json`（包含触发关键词、步骤指引与避坑规则），CLI 启动时便会自动发现并动态注册！
3. **任务智能匹配**：
   - 既可通过 `--sop <name>` 手动指定；
   - 也支持在你说出“帮我点一杯咖啡”时，系统根据关键词自动模糊匹配到对应 SOP，并在大模型推理过程中实时注入步骤指导与关键提醒！
